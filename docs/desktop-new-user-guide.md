# LocalSpace 桌面版 · 新用户指南

本指南面向不使用终端的普通用户:从安装到让 ChatGPT 操作你电脑上的项目,
全程只需点击鼠标。

## 它是什么?

LocalSpace 让 ChatGPT / Claude 直接读写你指定的项目文件夹:看代码、改文件、
跑测试、提交 Git。**所有文件都留在你的电脑上**,只有你亲自输入 Owner 密码
授权后,AI 才能访问;允许访问的目录范围也由你决定,越窄越安全。

## 第 1 步:首次配置(向导)

打开应用,首次会进入三步向导:

1. **选择项目目录** —— 点「选择文件夹」勾选要允许 AI 访问的项目文件夹。
   建议选择具体的项目文件夹(如 `D:\my-app`),不要选整个磁盘。
2. **本地端口** —— 不确定就保持默认 `7676`。
3. **选择接入方式**:
   - **仅本机使用(推荐)** —— ChatGPT / Claude 桌面版就装在这台电脑上?
     选这个,无需任何其他配置。
   - **远程访问** —— 想用手机或网页版 ChatGPT?需要一个公网地址
     (Cloudflare Tunnel、ngrok、cpolar 等),粘贴到输入框即可。

完成后请**复制并保存 Owner 密码**(下一步要用,之后随时可在主面板查看)。

## 第 2 步:启动服务

回到主面板,点「启动」。状态变为绿色的「运行中」即可。
(开机自启可在「设置」里打开,之后每次开机自动运行。)

## 第 3 步:连接 ChatGPT

**仅本机模式**:打开同机安装的 ChatGPT / Claude 桌面版 → 设置 → 连接器
→ 添加 MCP 服务器,粘贴主面板上的**本地 MCP 地址**(形如
`http://127.0.0.1:7680/mcp`)。

**远程模式**:把**公网 MCP 地址**填入任意设备的 ChatGPT / Claude MCP 设置。

## 第 4 步:Owner 授权(仅首次)

ChatGPT 第一次连接时,你的浏览器会弹出 LocalSpace 授权页——
粘贴 Owner 密码并确认。这相当于你亲口说"我允许这个 AI 访问我的目录"。
授权一次后,该客户端不再重复询问。

## 日常使用

- 在 ChatGPT 里直接说:「打开 D:\my-app,看看 git 状态」「修复这个报错并跑测试」
- 关闭窗口 = 最小化到托盘,服务继续运行;托盘菜单可彻底退出
- 出问题时点主面板「运行诊断」,把红绿结果截图即可寻求帮助
- 想增删允许的目录?主面板 →「重新配置…」

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 点「启动」报端口被占用 | 之前手动跑过 `localspace serve`?先关掉它;或向导里换个端口 |
| ChatGPT 连不上(远程模式) | 确认隧道在运行;公网地址是否带了 `/mcp`(应只填根路径) |
| 想换 Owner 密码 | 删除配置目录里的 `auth.json` 后「重新配置」,或用终端 `localspace init --force` |
| 服务状态红色「出错」 | 打开「日志」页查看原因;多数是端口冲突或核心未正确安装 |

## 安全须知

- 允许目录越窄越安全;敏感文件(如 `.env`)的修改需要你逐次批准
- Owner 密码等于你电脑上这些目录的钥匙,不要外传
- 只授权你信任的 AI 客户端;随时可在托盘退出服务"断开一切"
